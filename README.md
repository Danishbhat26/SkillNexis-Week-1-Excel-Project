# Skill Nexis Internship – Week 1

## Global Superstore Sales Performance Dashboard

This project was completed as part of my **Week 1 Skill Nexis Internship**.

### Objective

To analyze the Global Superstore 2016 dataset using Microsoft Excel and create a sales performance dashboard.

### Topics Covered

* Excel Basics and Navigation
* SUM, AVERAGE and COUNT formulas
* Data Cleaning Techniques
* Pivot Tables and Data Summarization
* Data Types and Descriptive Statistics
* Mean
* Median
* Mode
* Variance

### Dashboard Analysis

The dashboard analyzes:

* **Total Revenue**
* **Sales by Category**
* **Yearly Sales Trends**
* **Department-wise Revenue**

### Data Cleaning

The dataset was cleaned by removing duplicate records, handling missing essential values, standardizing date fields, and ensuring numeric fields were correctly formatted.

### Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Charts
* Excel Formulas
* Descriptive Statistics

### Dataset

**Global Superstore 2016**

### Project Output

The final Excel workbook contains:

* Cleaned dataset
* Excel formula examples
* Descriptive statistics
* Pivot-style summaries
* Sales performance dashboard
* Charts for sales analysis
